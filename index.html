Skill、MCP、Hook 有什麼差別？

Skill 是做事的方法與資源；MCP 是連接外部工具的協定；Hook 是指定事件發生時執行動作的機制。目錄與配置套件也會收錄在本站，但各自有清楚標記。

GPT / Codex 和 Claude Code 怎麼選？

本站的 Codex 標記主要指本機 Codex／支援 Skills 的 coding 工具，並不代表貼到一般 ChatGPT 就能安裝。Claude Code 是本機開發工具。共用 SKILL.md 格式不保證腳本、權限與依賴完全相容；以來源 README 的平台說明為準。

如何安裝與開始使用？

開啟卡片的來源，先讀 README 與 SKILL.md，再按該工具的官方方式安裝。Claude 官方目錄提供 plugin marketplace 說明；Codex 新入口請看 OpenAI Plugins。從一個工作流與兩三個常用專業 Skills 開始。

我的專案該封裝哪些規則？

以下是建議自製的 Skills，尚未提供安裝檔：

  • toefu-video：1080×1920、只改 scripts/ 與 docs/、沿用 Playwright＋ffmpeg、不新增依賴。
  • toefu-vocabulary-data：不覆寫原題庫、指定詞義的理解難度、批次輸出與人工抽查。
  • toefu-code-review：Claude 完成後提供 diff 與測試證據，由 Codex 獨立檢查，再由你確認。

Skill 本身不會自動啟動另一個工具；跨工具接力需要另設腳本或 Hook。

收藏與推薦度怎麼運作？

★★★★★：優先研究；★★★★☆：依需求選用；★★★☆☆：進階、探索或舊資源。收藏僅存在目前瀏覽器，沒有帳號同步或上傳。若瀏覽器限制儲存，收藏可在本次頁面暫時使用。

安裝前看哪裡？

看來源、授權、SKILL.md、scripts 與需要的存取權限。官方文件 Skills 也可能有個別授權；推薦不等於保證安全或適用。MCP 只授予任務所需的範圍。
